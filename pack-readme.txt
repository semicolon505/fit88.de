موقع fit88.de — مضر عجاج، اختصاصي تغذية علاجية
================================================

محتويات الأرشيف
---------------
- index.html        الصفحة الرئيسية
- about.html        من نحن
- services.html     الخدمات والبرامج
- blog.html         المدونة
- contact.html      تواصل معنا (نموذج + خريطة)
- impressum.html    بيانات الناشر (Impressum)
- datenschutz.html  سياسة الخصوصية (Datenschutz)
- 404.html          صفحة الخطأ
- src/fit88.css     ملف التنسيقات
- src/fit88.js      ملف الوظائف (اللغة، القائمة، الكوكيز، تأثيرات التمرير)

طريقة الاستخدام
---------------
1) فتح مباشر: فك ضغط الملف ثم افتح index.html بالمتصفح — كل شيء يعمل
   (تبديل اللغة عربي/ألماني، قائمة الجوال، نموذج التواصل عبر البريد).
2) استضافة حقيقية: ارفع محتويات المجلد كما هي إلى أي استضافة ثابتة
   (Netlify / Vercel / استضافة cPanel...) واجعل index.html الصفحة الافتراضية.

ملاحظة عن الصور
---------------
جميع صور الموقع الآن محلية ومرفقة داخل الأرشيف (مجلد src/img):
- logo.png            اللوغو الرسمي للموقع (يظهر في الهيدر والفوتر والأيقونة)
- hero-lineart.png    رسم الهيرو الخطي (Line-art)
- باقي الملفات SVG    رسوم توضيحية بهوية fit88 الخضراء (من نحن، المدونة، الخدمات، البرامج)
كلها تعمل بدون إنترنت، ولا تنضغط أبداً في أي حجم بفضل object-fit:contain.
لتعديل اللوغو مستقبلاً: استبدل ملف src/img/logo.png بنفس الاسم.
